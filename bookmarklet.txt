# bkmrklparsesave bookmarklet — one reusable javascript: URL for every site.
# Requires: Tampermonkey with the bkmrklparsesave extractor userscript installed.

## Install: Firefox
# 1. Right-click the bookmarks toolbar -> "Bookmark This Page..." (or Ctrl+D).
# 2. Name it e.g. "Extract". Paste the javascript: line below into the URL field.
# 3. Or simply drag the javascript: line from this file onto the bookmarks toolbar.

## Install: Chrome / Edge / Brave / Vivaldi
# 1. Open the bookmark manager (Ctrl+Shift+O / chrome://bookmarks).
# 2. Add a new bookmark, name e.g. "Extract".
# 3. Paste the javascript: line below into the URL field.
# 4. Chrome/Edge 138+: open the Tampermonkey extension details and turn ON
#    "Allow User Scripts" (older versions: enable Developer Mode under
#    chrome://extensions). Otherwise no userscript runs and nothing will answer.

## If a site blocks javascript: bookmarklets (CSP)
# Chrome ignores page CSP for bookmarklets; some Firefox pages still refuse them.
# Fallback: Tampermonkey menu -> "Extract this page" runs the same extraction.
